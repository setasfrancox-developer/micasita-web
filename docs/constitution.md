# Constitución de MiCasita

1. Solo HTML, CSS y JavaScript puros. Sin frameworks, dependencias ni herramientas de compilación.
2. No implementes funcionalidades que no estén aprobadas en la especificación del proyecto.
3. Mantén separada la estructura (`index.html`), los estilos (`styles.css`) y la lógica (`app.js`).
4. No instales dependencias para probar. Usa `node --check app.js` y Chrome DevTools para comprobar el formulario, el carrusel y la vista móvil.
5. No almacenes datos del formulario ni los envíes a servidores o correos reales sin autorización explícita.
6. Usa nombres descriptivos en código y escribe todos los textos de la interfaz y documentación en español.
